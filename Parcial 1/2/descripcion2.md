MIMIC-III DATASET
Explicación del dataset

El dataset MIMIC-III contiene información clínica de pacientes que estuvieron en unidades de cuidados intensivos. No es un solo archivo, sino un conjunto de varias tablas relacionadas, como pacientes, admisiones, tratamientos y signos vitales.

Para poder trabajar con este dataset, primero es necesario unir las tablas mediante identificadores comunes, ya que la información de un mismo paciente está distribuida en diferentes archivos.

Resultado / objetivo

Este dataset no tiene una única variable objetivo definida. El resultado depende del problema que se quiera plantear. Por ejemplo, se puede usar para:

Predecir si un paciente va a sobrevivir
Estimar el tiempo de hospitalización
Detectar enfermedades o condiciones médicas
Puntos clave del análisis
Los datos están distribuidos en múltiples tablas
Existe una gran cantidad de valores faltantes
Requiere unión de datos (JOIN) antes de modelar
Incluye información temporal (fechas y horas)
Trabajo realizado

Se realizó la comprensión de las tablas, la selección de variables relevantes, la limpieza de valores nulos y la integración de los datos en una estructura más simple para su uso en modelos.

Conclusión

Es un dataset complejo que requiere bastante preprocesamiento, pero es muy valioso porque trabaja con datos reales del área médica y permite resolver diferentes tipos de problemas.
