AUSTRALIAN CREDIT DATASET
Explicación del dataset

El Australian Credit Dataset contiene información de personas que solicitan crédito, y se utiliza para determinar si una solicitud debe ser aprobada o rechazada.

Es un dataset enfocado en problemas de clasificación y es más sencillo en comparación con otros datasets similares.

Resultado / objetivo

El objetivo es predecir si el crédito será aprobado o no:

1 → crédito aprobado
0 → crédito rechazado
Puntos clave del análisis
Es un problema de clasificación binaria
La mayoría de las variables ya están en formato numérico
No requiere tanto preprocesamiento
Las variables no tienen nombres descriptivos
Trabajo realizado

Se separaron las variables de entrada y la variable objetivo, se verificaron los datos, se aplicó normalización y se preparó el dataset para ser utilizado en modelos de clasificación.

Conclusión

Es un dataset práctico y fácil de trabajar, ideal para aplicar modelos de clasificación de manera directa sin necesidad de mucho procesamiento previo.
